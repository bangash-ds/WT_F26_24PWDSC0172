# Web Development Lab

This is a starter project for a web development lab exercise. It includes a clean landing page with responsive layout and simple interactivity.

## Files

- `index.html` — main page structure
- `style.css` — page styling and responsiveness
- `script.js` — small interactive behavior

## Run locally

Open the folder in a browser or serve it with a local HTTP server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Features

- Responsive navigation
- Hero section with call-to-action buttons
- Topic cards and practice checklist
- Theme toggle button

## Purpose

This project is suitable for a basic Web Technologies lab where students can practice HTML, CSS, and JavaScript fundamentals.
